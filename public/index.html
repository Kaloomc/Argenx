      Dépenses

      Comment corriger une dépense ?

      Glisse à gauche : catégorie. À droite : « à rembourser » (une dépense) ou « c'est un remboursement » (une somme reçue). Un appui : toutes les actions.

        Revolut en automatique

        …

        Importer un relevé Revolut

        Exporter depuis l'appli Revolut : onglet Accueil → touche ton compte en euros → … (ou Relevé) → Relevé → format Excel / CSV → choisis la période → Générer, puis enregistre le fichier.

        Tu peux réimporter une période qui chevauche la précédente : les opérations déjà connues sont ignorées.

        Cette somme est mise de côté sur le mois choisi : elle est retirée de ce qui reste à dépenser. L'appli suit les virements vers tes coffres Revolut (catégorie Épargne) jusqu'à atteindre le montant. 0 = rien à remettre.
